# Investigación de la librería SimPy - Unidad 4 Práctica 1

Este repositorio contiene la documentación y ejemplos prácticos sobre la librería **SimPy** de Python, enfocada en la simulación de eventos discretos.

## Contenido del Repositorio

A continuación, puedes navegar por los diferentes archivos de este proyecto haciendo clic en los enlaces:

* [¿Qué es SimPy?](que_es_simpy.md) - Una explicación sencilla sobre qué es esta librería y para qué se utiliza.
* [Ejemplo 1: Gasolinera](ejemplo1.md) - Simulación básica de autos llegando a cargar combustible.
* [Ejemplo 2: Lavado de autos](ejemplo2.md) - Simulación de un autolavado con múltiples máquinas de atención.
* [Ejemplo 3: Taquilla de cine](ejemplo3.md) - Simulación de clientes comprando boletos.
